# Skill: Continuous learning (Phase 3 design, not yet automated)

The loop is **Research → Hypothesis → Backtest → Gates → Holdout → Paper → Review**, with
controlled learning, never unrestricted self-modification.

1. **Learn from results:** each report says why a hypothesis failed (costs, regime, too few
   trades, unstable params). Record the lesson in `research_log/lessons.md`.
2. **Learn from trades** (Phase 4+): for each paper trade log entry reason, exit reason,
   whether the hypothesis held, whether conditions changed, and the cost paid.
3. **Propose** a new version or family. It enters the same pipeline and adds to N.
4. **Promote** only with human approval (constitution rule 3).

Budget: the more configs tried on a pair, the higher the bar (DSR). Spend trials on
hypotheses with an economic reason, not on parameter sweeps.
